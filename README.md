# Hillel: домашні завдання

Навчальний проєкт курсу Hillel з JavaScript. Це статична веб-сторінка. Кожне домашнє завдання лежить в окремому JavaScript-файлі, і сторінка завантажує його за вибором користувача.

## Структура

```
lesson_2/
  index.html              — заглушка уроку 2
lesson_3/
  index.html              — сторінка домашніх завдань
  index.js                — логіка сторінки: вибір групи і завдання, запуск скрипта
  constants.js            — конствтни та їх гетери
  utils.js                — спільні утиліти (getRandomInt)
  styles.css              — стилі сторінки
  home-work_2/            — завдання 2.1–2.5
  home-work_3/            — завдання 3.1–3.8
  home-work_4/            — завдання 4.1–4.5
```

## Як працює сторінка

1. Користувач обирає групу (Домашнє 2, 3 або 4), а потім завдання.
2. Сторінка перезавантажується з параметром `tab` в адресі.
3. `index.js` додає на сторінку тег `<script>` з файлом завдання, наприклад `home-work_4/home-work_4-5.js`.
4. Завдання зі списку `consoleHintTabs` у `constants.js` виводять результат у Console. Для них сторінка показує підказку.
5. Кнопка RESET відкриває сторінку без параметрів.

## Запуск

1. Відкрий `lesson_3/index.html` у браузері.
2. Для завдань, що виводять результат у Console, відкрий консоль розробника (F12, вкладка Console).

## Правила для файлів завдань

- Файл починається з коментаря з номером і умовою завдання.
- Розв'язок іде після коментаря. Альтернативні розв'язки залишаються закоментованими.
- Нове завдання додай у відповідний блок `subtabs` в `index.html`. Якщо воно виводить результат у Console, додай його також до `consoleHintTabs` у `constants.js`.
